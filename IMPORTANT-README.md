# OreSense AI - Backend
This is the **backend service** for OreSense AI, powering the application with APIs, business logic, and data management to support Life Cycle Assessment (LCA) workflows.
## ⚙️ Features
- RESTful API endpoints for frontend integration
- - Secure environment variable handling
  - - Built with Node.js/Express (customizable for future needs)
    - - Scalable architecture for data processing
## 🖇️ Frontend Repository: The frontend for this project is available here:
👉 [OreSense AI Frontend](https://github.com/Priyam1536/FRONTEND-ORESENSE)


Ensure your .env file is correctly set up before running the server.
